# gauss_row

Решение СЛАУ `Ax = b` методом Гаусса с выбором главного элемента по строке.

## Сборка

bash
# через make
make
./gauss_row 4 4 1

# через cmake
mkdir build && cd build
cmake .. && make
./gauss_row 4 4 1


Отладка: `make DEBUG=1` или `cmake -DCMAKE_BUILD_TYPE=Debug ..`

## Запуск


./gauss_row n m k [filename]


- `n` — размер матрицы
- `m` — сколько строк и столбцов печатать
- `k` — режим: `0` — из файла, `1..4` — по формуле
- `filename` — только при `k = 0`

Формулы:

| k | a(i,j) |
|---|---|
| 1 | n − max(i,j) + 1 |
| 2 | max(i,j) |
| 3 | \|i − j\| |
| 4 | 1 / (i + j − 1) |

## Примеры

bash
./gauss_row 4 4 1
./gauss_row 2000 6 1
./gauss_row 100 5 4
./gauss_row 4 4 0 a.txt


## Файлы

вид : | Файл | Что внутри |

| `main.c` | запуск, аргументы, время |
| `matr.c` / `matr.h` | чтение, формула, `b`, печать, нормы |
| `form.c` / `form.h` | функция `f(k,n,i,j)` |
| `Gau.c` / `Gau.h` | метод Гаусса |
| `Makefile`, `CMakeLists.txt` | сборка |

## Требования

- `gcc` 
- `make` или `cmake ≥ 3.10`
- память свободная 

## Ограничения

- Плотная матрица, время `O(n³)`.
- `n = 100 000` требует 80 ГБ — нереально.
- Гильберт (`k = 4`) теряет точность при `n ≥ 12`.

## Формат файла

`n × n` чисел, построчно. Пример для `n = 3`:

```
1 2 3
4 5 6
7 8 9
```
